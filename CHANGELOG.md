# Changelog

## v1.0 — Public release

- Built-in editable architecture Samples
- Resizable three-column workspace
- Blue Samples selector
- Scrollable Style & Connections controls
- Fixed Export panel
- Project save/open workflow
- Publication figure export to PNG, JPG, SVG, PDF, and EPS
- Surface-aware gaps and outside-junction control
- Random palettes and connection-width variation
- Path and cascade highlighting
- Windows launcher and root-level EXE build output
- Windows executable explicitly bundles Matplotlib export backends for PNG, JPG, SVG, PDF, and EPS
