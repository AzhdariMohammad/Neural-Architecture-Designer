# Contributing

Bug reports and focused feature requests are welcome.

Before submitting code changes:
1. Confirm the app launches on a clean Python environment.
2. Check that existing project files still load.
3. Check both Live Preview and exported output.
4. Avoid changing preset appearance unless the change is intentional and documented.
5. Keep generated folders such as `.venv`, `.pyinstaller_build`, `dist`, and `__pycache__` out of commits.
